Comment installer une application ?

🤖 Android

Ouvre l'application, puis touche « 📲 Installer l'application » en haut de l'écran. Sinon : menu ⋮ de Chrome → Ajouter à l'écran d'accueil.

🍎 iPhone

Ouvre l'application dans Safari, touche le bouton Partager (carré avec une flèche) → Sur l'écran d'accueil → Ajouter.

💻 Ordinateur

Ouvre l'application dans Chrome ou Edge, puis clique sur « 📲 Installer l'application », ou sur l'icône d'installation dans la barre d'adresse.
